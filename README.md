**CloudNewaBox**
**Project Description**

CloudNewaBox is a software engineering project based on a Newari food Bento Box service. The main purpose of this project is to provide customers with an easy way to explore and order traditional Newari foods.

The system allows customers to browse different Newari foods, create their own Bento Box, customize food preferences, select an occasion, add food to the cart, and place an order.

**Main Features**
Customer account creation
Customer login
Forgot and reset password
Browse Newari foods
Search and filter foods
Create a customized Bento Box
Customize spice, salt, and oil levels
Select an occasion
Add items to cart
Choose a payment method
Place an order
Project Purpose
The purpose of CloudNewaBox is to provide a simple digital platform for customers to enjoy traditional Newari food in a convenient Bento Box format. The project also helps demonstrate software engineering concepts such as user stories, acceptance criteria, system design, and user interface planning.

**Technologies**
HTML

Project Structure
The project contains different pages and features for customers and administrators. The customer side focuses on food browsing, Bento Box customization, ordering, and account management.

**Future Improvements**
Future improvements may include online payment integration, order tracking, delivery management, customer reviews, and a complete administrator dashboard.
